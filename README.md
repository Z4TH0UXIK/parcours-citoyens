# Parcours de conseillères citoyennes · Oyonnax

Application web (installable sur téléphone) présentant les frises de parcours de conseillères citoyennes d’Oyonnax.

- Frise interactive, curseur « Remonter le temps », filtres par type d’élément, vocabulaire.
- Vue verticale sur téléphone, frise horizontale sur ordinateur.
- Fonctionne hors connexion après la première ouverture.

Adresse : https://z4th0uxik.github.io/parcours-citoyens/

Polices : Atkinson Hyperlegible, Bricolage Grotesque, JetBrains Mono (licence SIL Open Font License, voir `fonts/OFL.txt`).
